🎵 MusicNojo

Guide d'utilisation

User guide

📂 Ouvrir une collection

« Ouvrir une collection… » (dans l'en-tête, ou Fichier → Ouvrir une collection… dans la barre de menus) ouvre le sélecteur natif macOS — il n'accepte que les fichiers .mucp.

  • Une collection .mucp d'une version de Music Collector différente de celle visée (20.3.2) est refusée avec un message clair, plutôt qu'un plantage.
  • Au tout premier lancement, MusicNojo affiche une collection d'exemple intégrée, entièrement fictive (12 albums inventés) — il y a toujours quelque chose à voir, sans jamais exposer de vraies données par défaut.
  • Chaque lancement suivant rouvre la même collection, exactement là où on l'avait laissée — onglet, regroupement, recherche, tri, vue, page et album sélectionné.

🎧 Parcourir la bibliothèque

Trois zones redimensionnables à la souris : le regroupement à gauche, la liste des albums en haut à droite, la fiche détail en bas à droite.

  • Regroupement par Artiste (par défaut), Genre, Format, Pays ou Label, avec une barre A→Z qui réduit la liste des valeurs affichées.
  • Vue liste ou grille (vignettes de pochettes), tri par titre/artiste/année/label, recherche par titre ou artiste, pagination à 60 albums par page.
  • Sous-collections multiples dans un même fichier — des onglets permettent de basculer entre elles.
  • Statistiques : comptes et répartitions par genre/ format/pays/label/décennie/année d'ajout. Les compteurs « N sans pochette » et « N sans artiste » sont cliquables ; dans la liste « sans pochette », chaque album ouvre un sélecteur de fichier pour lui poser une pochette immédiatement.
  • Fiche détail : pochette, titre, chaque rôle (artistes, compositeurs, chefs d'orchestre, musiciens, orchestres, chœurs), genres, étiquettes, label, format, pays, année, note, notes, UPC, date d'ajout, et la liste des pistes (par disque, s'il y en a plusieurs).

✏️ Ajouter, modifier, supprimer un album

  • Ajouter : un formulaire couvrant chaque champ (rôles, champs many-to-many, pistes une par ligne). Avant toute écriture, un aperçu liste chaque valeur saisie avec un badge « nouveau » sur celles qui n'existent pas encore — pour repérer une faute de frappe avant qu'elle devienne une entrée dupliquée permanente.
  • Le nouvel album rejoint l'onglet de sous-collection actif, et reçoit la date/heure actuelles comme date d'ajout — modifier l'album ne change jamais cette date.
  • Modifier : depuis la fiche détail, même formulaire pré-rempli, écriture immédiate (pas d'aperçu).
  • Supprimer : depuis la fiche détail, après confirmation.
  • Il n'est pas encore possible de choisir une pochette au moment de l'ajout — seul « set-cover » ensuite (liste « sans pochette » du panneau statistiques, ou en ligne de commande) en définit une.

🌐 Interface bilingue

La bascule EN / FR dans l'en-tête change toute l'interface — regroupement, liste, fiche détail, statistiques, formulaires. Le choix est mémorisé d'une session à l'autre.

Les messages renvoyés par l'application elle-même après une action restent en français quelle que soit la langue choisie, pour l'instant.

🛡️ Sécurité des données

Chaque écriture (ajout, modification, suppression, pochette) est précédée d'une sauvegarde horodatée du fichier.

MusicNojo peut ouvrir la vraie collection Music Collector en lecture seule, mais aucune écriture n'a d'exception pour elle. Toute écriture est aussi refusée si Music Collector lui-même est lancé — fermez-le d'abord.

🚧 Pas encore disponible

  • Changer la sous-collection d'un album en le modifiant (seul l'ajout en définit une).
  • Recherche en ligne pour pré-remplir une fiche à partir d'un code-barres/UPC ou d'une correspondance Discogs/ MusicBrainz.
  • Application pas encore signée/notariée par un compte développeur Apple — sans conséquence pour un usage personnel.

🔧 Pour aller plus loin

Pour un usage courant, l'application seule suffit. Pour les outils en ligne de commande (mc_export/ mc_add — export CSV/JSON/HTML, scripts), voir CLI.fr.md dans le dépôt. CHANGELOG.fr.md garde l'historique des versions publiées.

📂 Opening a collection

"Open Collection…" (in the header, or File → Open Collection… in the menu bar) opens the native macOS file picker — it only accepts .mucp files.

  • A .mucp collection from a Music Collector version other than the one targeted (20.3.2) is rejected with a clear message, rather than a crash.
  • On the very first launch, MusicNojo shows an entirely fictional bundled sample collection (12 invented albums) — there's always something to see, without ever exposing real data by default.
  • Every later launch reopens the same collection, exactly where it was left — active tab, grouping, search, sort, view, page and selected album are all remembered.

🎧 Browsing the library

Three zones, resizable with the mouse: grouping on the left, the album list at top right, the detail card at bottom right.

  • Grouping by Artist (default), Genre, Format, Country or Label, with an A→Z bar that narrows the listed values.
  • List or grid view (cover thumbnails), sort by title/artist/year/label, search by title or artist, pagination at 60 albums per page.
  • Multiple sub-collections in a single file — tabs switch between them.
  • Statistics: counts and breakdowns by genre/format/ country/label/decade/year added. The "N with no cover" and "N with no artist" counts are clickable; in the "no cover" list, each album opens a file picker to set its cover right away.
  • Detail card: cover, title, every role (artists, composers, conductors, musicians, orchestras, choruses), genres, tags, label, format, country, year, rating, notes, UPC, date added, and the track listing (by disc, when there's more than one).

✏️ Adding, editing, deleting an album

  • Add: a form covering every field (roles, many-to- many fields, tracks one per line). Before anything is written, a preview lists every value typed, with a "new" badge on the ones that don't already exist — catching a typo before it becomes a permanent duplicate entry.
  • The new album joins the active sub-collection tab, and is stamped with the current date/time as its date added — editing it later never changes this date.
  • Edit: from the detail card, same pre-filled form, writes immediately (no preview).
  • Delete: from the detail card, after confirmation.
  • There is no way yet to pick a cover when adding an album — only "set-cover" afterward (the "no cover" list in the statistics panel, or from the command line) sets one.

🌐 Bilingual interface

The EN / FR toggle in the header switches the whole interface — grouping, list, detail card, statistics, forms. The choice is remembered from one session to the next.

Messages returned by the application itself after an action stay in French regardless of the chosen language, for now.

🛡️ Data safety

Every write (add, edit, delete, cover) is preceded by a timestamped backup of the file.

MusicNojo can open the real Music Collector collection in read-only mode, but no write has any exception for it. Every write is also refused if Music Collector itself is running — close it first.

🚧 Not available yet

  • Changing an album's sub-collection on edit (only add sets one).
  • Online lookup to pre-fill a record from a barcode/UPC or a Discogs/MusicBrainz match.
  • Not yet code-signed/notarized with an Apple developer account — no consequence for personal use.

🔧 Going further

For everyday use, the application alone is enough. For the command-line tools (mc_export/mc_add — CSV/JSON/HTML export, scripts), see CLI.md in the repository. CHANGELOG.md keeps the history of published versions.
